## Test isolation and practical limits
- Mutation fixtures use randomly named disposable SQL databases and separate temporary attachment folders. Their cleanup is checked before shutdown. Live workflow decisions were not submitted during read-only browser inspections.
- Existing authorized demo accounts were used to view the local application. One committee demo account also has the sourcing-officer role; that is an assigned-role configuration, not a role bypass.
- Browser sweep covers main role pages and representative linked details across all 13 accounts. State-changing edge cases are covered in isolated HTTP tests rather than performed on the user's tenders.
- Automated WCAG checks supplement keyboard and visual inspection. They do not constitute a full screen-reader audit or accessibility certification.
- Actual biometric hardware/passkey enrollment, camera capture, real SMTP delivery, external AI quality/availability, production deployment configuration, load testing and browser/device combinations beyond this local Chrome run are not certified by this session. Report-generation tests use deterministic AI fixtures where required.
- Optional filters remain accessible through native disclosures. Wide data tables may scroll within their labelled containers on narrow screens; the page itself must not overflow horizontally.
